# Учебный frontend-проект ShopProject

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта — разработка многостраничного сайта интернет-магазина в рамках контрольной работы №1.

## Структура проекта

- `index.html` — главная страница интернет-магазина;
- `css/style.css` — стили сайта;
- `js/main.js` — JavaScript для работы с модальным окном и формой;
- `images/` — изображения проекта;
- `.gitignore` — исключения Git;
- `README.md` — описание проекта.
- `catalog.html` — каталог компьютерной техники;
- `contacts.html` — контактная информация.

## Используемые технологии

- HTML5 — семантическая структура страниц и формы;
- CSS3 — оформление сайта и модального окна;
- JavaScript — обработка событий и валидация формы;
- Git и GitHub — контроль версий;
- GitHub Pages — публикация сайта.

## Контрольная работа №1

**Тема:** «HTML и CSS: разработка многостраничного сайта».

**Цель:** разработать многостраничный сайт интернет-магазина.

Итоговый проект должен включать пять страниц: главную, каталог, страницу товара, оформление заявки и контакты.

Также предусмотрены семантическая HTML-разметка, навигация, карточки товаров, таблица характеристик, форма заявки, модальное окно, Flexbox, CSS Grid и БЭМ.

## История выполнения

**Практическая работа №1.** Создан Git-репозиторий, выполнена первоначальная настройка проекта и публикация на GitHub.

**Практическая работа №2.** Разработана главная страница с семантическими HTML-элементами, навигацией, карточками товаров и базовым CSS-оформлением.

**Практическая работа №3.** Добавлено модальное окно оформления заявки с использованием HTML, CSS и JavaScript. Реализованы открытие и закрытие окна, проверка обязательных полей, электронной почты и телефона, а также имитация отправки заявки.

**Практическая работа №4.** Добавлены CSS-переменные для цветов, отступов и скруглений. Упорядочена структура CSS, реализованы состояния :hover, :focus-visible, :disabled и оформление ошибочных полей.

**Практическая работа №5.** Созданы страницы каталога и контактов, реализована единая навигация между страницами, добавлены хлебные крошки и якорные ссылки. Использована семантическая HTML-разметка.

**Практическая работа №6.** Реализована горизонтальная навигация через Flexbox, сетка товаров через CSS Grid, выравнивание содержимого карточек и двухколоночный каталог с панелью фильтров. Добавлена адаптация сеток для небольших экранов.
## Текущий статус

Реализована главная страница интернет-магазина с базовым оформлением и интерактивной формой заявки. Разработка остальных страниц продолжается.
