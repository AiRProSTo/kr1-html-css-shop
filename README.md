# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `css/style.css` — файл стилей;
- `images/` — папка для изображений;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML;
- CSS;
- Git;
- GitHub.

## Текущий статус

Создана стартовая страница учебного интернет-магазина с семантической HTML-разметкой и базовым CSS-оформлением.
Постановка контрольной работы №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Цель контрольной работы — разработать многостраничный сайт интернет-магазина или каталога услуг.

Проект должен включать:

    главную страницу;

    страницу каталога;

    страницу отдельного товара;

    страницу оформления заявки;

    страницу контактов;

    семантическую HTML-разметку;

    единую навигацию;

    карточки товаров;

    таблицу характеристик;

    форму заявки;

    модальное окно;

    внешний CSS-файл;

    использование Flexbox, CSS Grid и БЭМ.
